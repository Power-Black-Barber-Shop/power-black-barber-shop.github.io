# Power Black Barber Shop

Site estático da barbearia. Cada atualização enviada para a branch `main` publica uma nova versão pelo GitHub Pages.

## Arquivos principais

- `index.html` — conteúdo e formulário de agendamento
- `style.css` — estilos responsivos
- `Script.js` — menu e envio do pedido pelo WhatsApp
- `uploads/power-black.png` — arte da barbearia

O formulário prepara uma mensagem com serviço, data e horário para o WhatsApp **(86) 99541-2466**. O horário solicitado é confirmado pela barbearia.
